Jogo

Tranca Letra

Teste sua criatividade e rapidez em um jogo de palavras com diferentes categorias e níveis de dificuldade. Escolha uma letra e encontre uma palavra que se encaixe no tema sem repetir a letra inicial das palavras anteriores.

Disponível no Google Play
RECURSOS

Pense rápido e não repita as letras

Escolha suas configurações, encontre palavras para diferentes categorias e tente superar seus amigos antes que o tempo acabe.

Diversas Categorias

Jogue com temas como cidades, marcas, coisas de Natal, personagens, cantores e muitos outros.

Dois Modos de Jogo

Escolha entre o Modo Livre, com qualquer letra disponível, ou o Modo Sorteio, em que você deve usar a letra sorteada.

Tempo para Pensar

Defina quanto tempo cada jogador terá para pensar em uma palavra. Se o tempo acabar, o jogador é eliminado.

Jogue em Grupo

Configure a quantidade de jogadores e as letras disponíveis para criar uma partida do jeito que você quiser.

PRIMEIROS PASSOS

Como jogar?

EXPLICAÇÃO GERAL SOBRE COMO UTILIZAR O APLICATIVO.

  1. Configure a quantidade de jogadores, as letras disponíveis e o tempo de cada rodada.
  2. Escolha o nível de dificuldade e aguarde a categoria ser sorteada.
  3. Na sua vez, fale uma palavra que se encaixe na categoria sem repetir uma letra inicial já utilizada.
  4. Se a palavra for aceita pelos demais jogadores, confirme para passar a vez. Se o tempo acabar, o jogador é eliminado.
